# ChatGPT Custom GPT 配置

## 简介

将微信公众号合规审查部署为 ChatGPT Custom GPT。

## 创建步骤

1. 打开 ChatGPT，进入「Explore GPTs」→「Create」
2. 在 Configure 页面填写以下内容

---

## GPT 配置

### 名称

```
公众号合规审查
```

### 描述

```
审查微信公众号文章内容是否违反微信公众平台运营规范和中国网络信息内容生态治理规定。逐段标注风险等级，输出结构化审查报告。
```

### 指令

将 `prompt.md` 的内容粘贴到此处。

### 会话起手（Conversation starters）

- 帮我审一下这篇公众号文章
- 检查这篇文章能不能发
- 这篇文章有没有违规风险
- 提交一篇时评文章请审查

### 知识文件（Knowledge）

上传 `references/wechat-guidelines.md` 作为知识库文件。

---

## 注意事项

- 本 GPT 只输出审查报告，不做发布拦截
- 审查标准基于微信公众平台公开运营规范
- 最终发布决策由用户自行判断

---

## 使用说明

### 触发审查

创建完成 GPT 后，打开对话，直接粘贴文章内容即可。以下任意说法均可触发审查：

- `帮我审一下这篇`
- `检查这篇文章能不能发`
- `有没有违规风险`
- `审一下`

GPT 会自动将内容按审查维度逐段扫描，输出结构化报告。

### 交互示例

```
你：帮我审一下这篇文章

（粘贴全文）

GPT：## 🔍 合规审查报告
     **文章**：XXX
     **文章类型**：普通
     **风险等级**：🟡 需注意
     ...

你：第3段具体哪里有问题？

GPT：（详细解释触发原因和修改方向）
```

### 追问能力

拿到报告后可以继续对话：

- `帮我重写第 3 段`
- `这段具体触发了哪条规则`
- `给出 3 个替换方案`
- `如果我改成 XXX 还会有风险吗`

### 字数限制

Custom GPT 对超长文章有上下文限制，建议：

- 单次审查不超过 8000 字
- 长文分段粘贴，逐段审查
- 如果文章有 files 引用，可直接上传文件让 GPT 读取
